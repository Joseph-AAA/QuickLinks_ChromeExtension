🚀 Launchpad — Chrome Extension

A personalized Chrome New Tab extension built with React, Vite, and Tailwind CSS.

Launchpad replaces Chrome's default New Tab page with a clean dashboard featuring quick links, weather information, search, and dynamic wallpapers.

✨ Features
🕐 Dynamic Greeting

Displays Good Morning or Good Evening based on the current time.

🌤️ Weather Widget
Current temperature
Day/night detection
Weather icons based on weather codes
Location information
Powered by the Open-Meteo API
🔗 Quick Links
Add custom shortcuts
Automatically displays website favicons
Open websites directly from the New Tab page
Delete shortcuts
Saves shortcuts using localStorage
🖼️ Dynamic Background

Fetches a random wallpaper from the Unsplash API.

🔍 Search

Search the web directly from the Launchpad New Tab page.

📱 Responsive Design

Designed to work across desktop, tablet, and mobile screen sizes.
